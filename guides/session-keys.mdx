# Session Keys

Session keys enable smooth UX by delegating limited authority to a temporary key, avoiding repeated biometric prompts.

## Why Session Keys?

Without session keys, every action requires biometric authentication:

```
Transfer 1 → FaceID prompt
Transfer 2 → FaceID prompt
Transfer 3 → FaceID prompt
```

With session keys:

```
Create session → FaceID prompt (once)
Transfer 1 → Auto-signed ✓
Transfer 2 → Auto-signed ✓
Transfer 3 → Auto-signed ✓
```

## Create a Session

```typescript
import { createSDK } from '@veridex/sdk';
import { parseEther } from 'ethers';

const sdk = createSDK('base', {
  network: 'testnet',
  relayerUrl: 'https://relayer.veridex.network',
});

// Login first
await sdk.passkey.login();

// Create a session with limits
const session = await sdk.sessions.create({
  duration: 3600, // 1 hour (in seconds)
  maxValue: parseEther('0.1'), // Max 0.1 ETH worth of transfers
});

console.log('Session created:', session.id);
console.log('Expires at:', new Date(session.expiresAt));
```

## Session Constraints

You can limit sessions in multiple ways:

### Time Limit

```typescript
const session = await sdk.sessions.create({
  duration: 3600, // 1 hour
});
```

### Value Limit

```typescript
const session = await sdk.sessions.create({
  duration: 3600,
  maxValue: parseEther('0.5'), // Max $500 worth (USD equivalent)
});
```

### Token Whitelist

```typescript
const USDC = '0x036CbD53842c5426634e7929541eC2318f3dCF7e';
const WETH = '0x4200000000000000000000000000000000000006';

const session = await sdk.sessions.create({
  duration: 3600,
  allowedTokens: [USDC, WETH], // Only these tokens can be transferred
});
```

### Recipient Whitelist

```typescript
const session = await sdk.sessions.create({
  duration: 3600,
  allowedRecipients: [
    '0x742d35Cc6634C0532925a3b844Bc9e7595f5A234', // Specific address
    '0xA1B2C3D4E5F6789012345678901234567890ABCD', // Another address
  ],
});
```

### Combined Constraints

```typescript
const session = await sdk.sessions.create({
  duration: 1800, // 30 minutes
  maxValue: parseEther('0.05'), // Max 0.05 ETH worth
  allowedTokens: [USDC], // USDC only
  allowedRecipients: [merchantAddress], // Only to merchant
});
```

## Use Session for Transfers

Once a session is created, transfers use it automatically:

```typescript
// Session is active
const session = await sdk.sessions.create({ duration: 3600 });

// These transfers don't prompt for biometric
await sdk.transfer({ token: USDC, recipient: addr1, amount: amount1 });
await sdk.transfer({ token: USDC, recipient: addr2, amount: amount2 });
await sdk.transfer({ token: USDC, recipient: addr3, amount: amount3 });
// All auto-signed! ✓
```

## Check Session Status

```typescript
// Get active session
const activeSession = sdk.sessions.getActive();

if (activeSession) {
  console.log('Session ID:', activeSession.id);
  console.log('Expires:', new Date(activeSession.expiresAt));
  console.log('Remaining value:', activeSession.remainingValue);
  console.log('Used value:', activeSession.usedValue);
} else {
  console.log('No active session');
}
```

## Revoke Session

```typescript
// Revoke the active session
await sdk.sessions.revoke();

console.log('Session revoked');

// Now transfers require biometric again
```

## Session Persistence

Sessions are stored in memory by default and persist across page reloads via localStorage:

```typescript
// Session survives page reload
const session = await sdk.sessions.create({ duration: 3600 });

// After page reload...
const restored = sdk.sessions.getActive();
console.log('Session restored:', restored?.id);
```

## React Example

```tsx
import { useState, useEffect } from 'react';
import { createSDK } from '@veridex/sdk';
import { parseEther, parseUnits } from 'ethers';

const sdk = createSDK('base', { 
  network: 'testnet',
  relayerUrl: 'https://relayer.veridex.network',
});

export function SessionManager() {
  const [session, setSession] = useState<any>(null);
  const [loading, setLoading] = useState(false);

  // Check for existing session on mount
  useEffect(() => {
    const active = sdk.sessions.getActive();
    if (active) {
      setSession(active);
    }
  }, []);

  const createSession = async () => {
    setLoading(true);
    try {
      const newSession = await sdk.sessions.create({
        duration: 3600,
        maxValue: parseEther('0.1'),
      });
      setSession(newSession);
    } catch (error) {
      console.error('Failed to create session:', error);
    }
    setLoading(false);
  };

  const revokeSession = async () => {
    await sdk.sessions.revoke();
    setSession(null);
  };

  if (session) {
    const expiresIn = Math.floor((session.expiresAt - Date.now()) / 1000 / 60);
    
    return (
      <div className="p-4 bg-green-50 rounded-lg">
        <h3 className="font-bold text-green-800">Session Active</h3>
        <p className="text-sm text-green-600">
          Expires in {expiresIn} minutes
        </p>
        <p className="text-sm text-green-600">
          Remaining: {session.remainingValue} wei
        </p>
        <button
          onClick={revokeSession}
          className="mt-2 text-red-600 text-sm underline"
        >
          Revoke Session
        </button>
      </div>
    );
  }

  return (
    <div className="p-4 bg-gray-50 rounded-lg">
      <h3 className="font-bold">No Active Session</h3>
      <p className="text-sm text-gray-600">
        Create a session for smoother transactions
      </p>
      <button
        onClick={createSession}
        disabled={loading}
        className="mt-2 bg-blue-600 text-white px-4 py-2 rounded-lg text-sm"
      >
        {loading ? 'Creating...' : 'Create 1-Hour Session'}
      </button>
    </div>
  );
}
```

## Batch Transactions

Sessions are perfect for batch operations:

```typescript
const session = await sdk.sessions.create({
  duration: 300, // 5 minutes
  maxValue: parseEther('1'), // 1 ETH worth
});

// Batch multiple transfers
const recipients = [
  { address: '0x...', amount: parseUnits('10', 6) },
  { address: '0x...', amount: parseUnits('20', 6) },
  { address: '0x...', amount: parseUnits('30', 6) },
];

for (const { address, amount } of recipients) {
  await sdk.transfer({
    token: USDC,
    recipient: address,
    amount,
  });
}
// All executed with single initial biometric! ✓

// Revoke when done
await sdk.sessions.revoke();
```

## Security Considerations

<Callout type="warning">
  Session keys have access to your vault within their constraints. Only create sessions when needed and revoke when done.
</Callout>

Best practices:

1. **Short durations**: Use the minimum needed duration
2. **Tight limits**: Set value limits appropriate for the use case
3. **Token whitelist**: Only allow tokens that will be used
4. **Revoke when done**: Don't leave sessions open unnecessarily
5. **Trusted devices only**: Don't create sessions on shared devices

## Error Handling

```typescript
try {
  const session = await sdk.sessions.create({
    duration: 3600,
    maxValue: parseEther('0.1'),
  });
} catch (error) {
  if (error.code === 'SESSION_EXISTS') {
    console.log('Session already active, revoke first');
  } else if (error.code === 'USER_CANCELLED') {
    console.log('User cancelled biometric prompt');
  } else {
    console.error('Failed to create session:', error);
  }
}
```

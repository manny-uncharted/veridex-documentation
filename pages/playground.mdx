## What's in the playground

| File | What it does |
|------|-------------|
| `src/main.ts` | Browser flow for passkey registration, policy confirmation, and relayer submission when a relayer URL is configured. |
| `src/policies.ts` | Example policy: per-tx max value with a label. Edit and re-run to see the transfer get rejected. |
| `src/trace-view.ts` | Renders a signed-trace stub inline so you can see exactly what got recorded. |
| `README.md` | Step-by-step walkthrough mirroring the [Developer Quickstart](/quickstarts/developer). |

## Five-minute path

1. Click **Open the playground ↗** above.
2. When Stackblitz finishes booting, hit the **Run** button (or wait for autorun).
3. In the preview pane, click **1. Register passkey** - your browser prompts for FaceID/TouchID.
4. Click **2. Confirm policy** - confirms the per-transaction maximum the Playground will enforce.
5. Relayer submission requires a separately configured, reachable relayer. Check
  [service status](/resources/service-status) before expecting an on-chain result.

## Current availability

The former public relayer and Developer Portal hostnames are reserved but not
currently deployed. Do not use them as SDK defaults. Run a relayer you control,
or use the self-hosted Stellar evaluator while the public services are being
restored.

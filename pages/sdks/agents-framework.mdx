# Agents Framework (`@veridex/agents`)

A general-purpose TypeScript agent runtime with tools, hooks, memory, checkpoints, transports, and policy-aware execution.

## Installation

```bash
npm install @veridex/agents zod
```

## Overview

The agents framework provides the runtime infrastructure for building AI agents that execute within Veridex's bounded authority model. It integrates with the Agent SDK for session management and the relayer for governance.
